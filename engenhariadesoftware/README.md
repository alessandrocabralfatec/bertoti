## 1 - O que significa Engenharia de Software?

Existem algumas confusões envolvendo a expressão Engenharia de Software. Por um lado, ela se confunde com Ciência da Computação ou Desenvolvimento de Softwares. Por outro lado, ela é comparada às outras Engenharias, como Civil, Elétrica, Mecânica etc...
Para desfazer essa confusão, saiba que:
O termo engenharia refere-se ao fato de que ela é mais o que a mera programação de software. Envolve usar métodos e práticas mais sofisticadas para criar Software.
O termo Software, ao diferenciar de outras engenharias, denota o fato de que estamos trabalhando com algo intangível, ou até invisível.
